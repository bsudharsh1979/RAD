# Evidence model

| Type | Meaning | Badge |
| --- | --- | --- |
| COURSE_SOURCE | In the NVIDIA notebooks/slides | 🔵 |
| EXPECTED_RESULT | Course/notebook says it should happen; no stored execution | 🟡 |
| SIMULATED_RESULT | TwinStateEngine | 🟣 |
| ACTUAL_RUN | Imported telemetry or a real provider call | 🟢 |
| TUTOR_INTERPRETATION | Model synthesis | ⚪ |
| EXTERNAL_RESEARCH | Perplexity / web | 🟠 |

Never render a simulation as a measurement. This repository’s notebooks have **no stored outputs**.
